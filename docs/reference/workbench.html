Slick Bets, an NBA prediction model

My first Claude Code project: an NBA prediction app that picked 71.5% of game winners over 648 games, tracked live.

The problem

I wanted to know if I could build a model that predicts NBA games well enough to trust, and whether it could find bets where the sportsbooks' odds were off. I also wanted to learn how to build software with Claude Code. This was my first real project with it.

How I built it

I directed Claude Code through every part of it over about ten weeks. I set the goals, made the calls on the model and the product, and reviewed everything before it shipped. Three decisions shaped it:

  • I cut the betting features when the value picks weren't right, and narrowed the app to the one thing the model could do well, which was picking winners.
  • I tuned the model with a backtest that replayed the season across 840 combinations of settings.
  • I learned to run software in production by running into its problems, and turned each fix into a written rule so Claude wouldn't repeat the mistake.
